이 입력란은 GitHub 저장소를 수정하거나 모델을 학습시키지 않습니다. 다른 컴퓨터나 다른 사람의 사이트에는 반영되지 않습니다. 비공개 창·브라우저 데이터 삭제 시 사라질 수 있으므로 다운로드해서 보관하세요.

1. CSV / JSON 후보 자료 불러오기

정규화된 CSV 또는 기록 배열 형식의 JSON을 지원합니다. 최소 열: sample_id, metric, two_pr. DOI, 원문 위치, 공정 조건도 함께 제공하는 것을 권장합니다.

2Pr 값은 metric이 정확히 “2Pr”이고 two_pr가 숫자인 경우만 2Pr 후보로 표시합니다. 업로드 자료는 모두 미승인입니다. Excel/PDF 직접 해석은 이 페이지에서 지원하지 않습니다.

2. 논문 · ChatGPT 정리 내용 메모

메모는 자동으로 실험 데이터나 학습 레이블로 변환되지 않습니다. ChatGPT가 정리한 수치도 원문과 대조해야 합니다.

사이트 전체에 자료를 반영하려면 다운로드한 파일이나 원본 PDF·엑셀을 이 사이트를 만든 ChatGPT 대화에 전달하세요. 실제 반영에는 저장소 수정 및 재배포가 필요합니다.

05 / DATA INTEGRITY

예측 전에 확인할 사항

원본과 승인 분리

DOI·샘플·Figure/Table·원본 행을 보존해야 합니다. 숫자 확인이나 엑셀의 ‘권장’ 표시는 학습 승인이 아닙니다.

측정·공정 조건 확인

RTA/MWA/Furnace, Pr/2Pr, P-E/PUND, pristine/wake-up을 구분해야 합니다. 삽입층과 전극 전체 두께도 별도로 확인해야 합니다.

논문 단위 모델 검증

동일 DOI가 학습·검증에 동시에 포함되지 않도록 하고, Random Forest를 기준 모델과 비교해야 합니다. 학습 범위 밖 조건은 경고하거나 예측을 차단해야 합니다.

이 페이지는 아직 실제 예측 서버와 연결되지 않았습니다.
데이터가 늘어도 이 페이지에서 자동 학습되지는 않습니다. 원문 검토와 Python 모델 학습·검증을 거쳐야 예측 기능을 연결할 수 있습니다.
